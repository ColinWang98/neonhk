# Shanxi reference voices

Put short Shanxi dialect or Shanxi Mandarin reference clips here for local CosyVoice generation.

Recommended layout:

```txt
tts_sidecar/reference/shanxi/
  middle_female/
    sample-01.wav
  middle_male/
    sample-01.wav
  older_female/
    sample-01.wav
  older_male/
    sample-01.wav
```

You can also place a single `.wav`, `.flac`, or `.mp3` directly in this folder.

Use clips you have permission to use. A clean 10-30 second single-speaker recording works best.
