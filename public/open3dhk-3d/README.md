# KTX2 texture decoder

`basis_transcoder.js` and `basis_transcoder.wasm` are copied unchanged from
`three@0.180.0/examples/jsm/libs/basis/`. They decode the compressed textures
in LandsD's official 3D Tiles. Keep these files aligned with the Three.js version.
